# Personal Portfolio Website

---

## Description

A modern, fully responsive personal portfolio website designed to showcase professional skills, projects, and experience. This website serves as a digital resume and portfolio platform, featuring a clean design, multilingual support, and theme customization options.

The Personal Portfolio Website combines professional aesthetics with functional design, showcasing an individual's technical skills, completed projects, educational background, and contact information. The platform is built with modern web standards and includes advanced features such as real-time language switching and dark/light theme support.

The primary objective of this project is to provide a professional online presence that effectively communicates skills, experience, and project work to potential clients, employers, and collaborators through an engaging and accessible web interface.

---

## Technologies

The following technologies were utilized in the development of this website:

- **HTML5** - Semantic markup and structured content
- **CSS3** - Modern styling with responsive design and animations
- **JavaScript (ES6+)** - Dynamic functionality and interactivity
- **LocalStorage API** - Theme and language preference persistence
- **FormSpree** - Email form backend integration

## Installation

Getting started with the Personal Portfolio Website is simple:

1. **Clone or download** this repository to your computer
2. **Navigate** to the project folder
3. **Open** the `index.html` file in any modern web browser
4. **Customize** the content to reflect your personal information

**No server or dependencies required** — this is a static website that runs entirely in your browser.

---

## Usage

Using the Personal Portfolio Website:

1. **Open** the website in your web browser
2. **Navigate** using the header menu to different sections
3. **Switch languages** using the language toggle button (TR/ENG)
4. **Toggle theme** using the sun/moon icon button
5. **View skills** - Browse the skills section with proficiency indicators
6. **Explore projects** - Filter and view portfolio projects
7. **Contact** - Use WhatsApp, Telegram, or the contact form to reach out

## How It Works

The website operates using a client-side architecture:

1. **Content Rendering** - Static HTML content loaded on page load
2. **Dynamic Updates** - JavaScript enables language and theme switching
3. **Storage** - Browser LocalStorage persists user preferences
4. **Navigation** - Anchor links enable smooth section navigation
5. **Form Submission** - Contact form submits to FormSpree backend
